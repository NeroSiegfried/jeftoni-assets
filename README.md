# jeftoni-assets

Static asset host for the Jeftoni Nigeria Limited Wix site (Route A in
`wix/MIGRATION.md` of the main repository): stylesheets, the behaviour script,
the two self-hosted fonts and the photographs and video that are not in the
Wix Media library.

Generated by `site/build.mjs` — do not edit here; rebuild and re-copy
`dist-wix/{styles,scripts,fonts,media}`.
